# Public gazetteer of common given names, one per line, case-insensitive.
#
# WHAT THIS IS FOR. The distribution gate's capitalised-bigram detector
# (main/privacy/index_scan.py) has to decide whether "Xxxx Yyyy" in a built
# collection is a person the alias map missed, or an ordinary capitalised
# phrase ("Applicable Legislation", "Nord Norge"). It RETAINS a candidate when
# the first token is a plausible given name. Retention, not subtraction: a
# filter built the other way round — drop anything that looks like a name —
# removes exactly the category the gate exists to find.
#
# WHERE THE NAMES COME FROM. Common given names in public use: the names
# Norwegian name statistics publish year after year, plus common given names
# from the other locales this corpus's authors write in. Nothing here is
# derived from any indexed corpus, and no surname appears. That is deliberate:
# a list built from the corpus would itself be a fingerprint of who works
# there, which is the thing this whole campaign removes.
#
# THE CORPUS-SPECIFIC HALF IS NOT HERE. Rare given names that occur in the
# private map (its entries' first tokens and its `bare_given_name_residual`)
# are unioned in at RUNTIME from the gitignored map, never written here. A
# clone with no private sub-repo therefore gets a weaker detector, which is
# correct: without the map there is nothing to certify anyway.
#
# ADDING A NAME. Only add names that are common in public use somewhere. If a
# name is only interesting because it appears in this machine's corpus, it
# belongs in the private map, not in this file.
